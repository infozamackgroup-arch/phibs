# Phibs Luxury Homes - website + owner admin

Files go in the ROOT of the GitHub repo (no folders): server.js, package.json, index.html, booking.html,
admin.html, admin.js, phibs-logo.png and all the phibs-*.jpg / "phibs room N.jpeg" photos.

Render: Web Service, Build Command `npm install`, Start Command `node server.js`
Environment: NODE_VERSION=22.23.5, ADMIN_PASSWORD=<owner password>, DATA_DIR=/var/data, DATABASE_URL=<old database link>
Disk: mount path /var/data
Admin page: https://<your-site>/admin
